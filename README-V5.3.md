# Guitar Ranked V5.3

Nouveautés :
- comptes joueurs avec pseudo ;
- progression sauvegardée par morceau ;
- pourcentage calculé automatiquement sur le nombre actuel de morceaux du rank ;
- déblocage du rank suivant à 80 %, avec morceau Boss obligatoire s'il y en a un ;
- morceau Boss / Rank Up configurable depuis l'admin ;
- technique, accordage et BPM configurables ;
- filtres dans Partie rapide ;
- bouton Signaler sur les commentaires et la FAQ ;
- sécurisation des droits admin maintenant que des comptes joueurs existent.

Après le déploiement GitHub/Vercel, exécuter `supabase-v5.3-progression.sql` une fois dans Supabase SQL Editor.
